# FocusGuard — Student Attention Monitor

FocusGuard is a web application designed to help monitor student attention during learning sessions using computer vision.

## Features

- Student attention monitoring interface
- Camera-based facial landmark detection, where configured
- Attention indicators and session monitoring
- Dashboard for viewing monitoring information

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase (where configured)

## Getting Started

### Requirements
- Node.js
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

## Configuration

If the project uses Supabase, configure the required environment variables in a local `.env` file. Never commit private credentials to GitHub.

## Project Status

This project is under development. Actual monitoring capabilities depend on the implemented camera, detection, and data-integration features.
